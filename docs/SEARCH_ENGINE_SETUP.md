# Search engine setup — Google Search Console + Bing Webmaster Tools

This file documents the manual steps to wire gileara.org into the
search engines Google and Bing use to crawl and rank the web.

The code side is done — `src/app/layout.tsx` reads
`GOOGLE_SITE_VERIFICATION`, `BING_SITE_VERIFICATION`, and
`YANDEX_SITE_VERIFICATION` from the environment and emits the
corresponding `<meta name="...">` tag on every page. Until you
paste the codes from each tool, no tag is rendered.

## What you need

- A Google account with access to [Google Search Console](https://search.google.com/search-console/about)
- A Microsoft account with access to [Bing Webmaster Tools](https://www.bing.com/webmasters)
- Access to the DNS records for `gileara.org` (or the ability to
  upload an HTML file to the site root — but DNS is recommended)

---

## Google Search Console

### 1. Add the property

1. Go to https://search.google.com/search-console/welcome
2. Click **Add property** → **URL prefix** → enter
   `https://gileara.org`
3. Choose **HTML tag** verification (easiest, already wired in
   the code)
4. Google will show you a meta tag like:

   ```html
   <meta name="google-site-verification" content="abc123...xyz" />
   ```

### 2. Paste the code into the env

1. Copy the value after `content=` (e.g. `abc123...xyz`)
2. Edit `.env.production` (and `.env.local` for the dev server)
3. Add or update:

   ```
   GOOGLE_SITE_VERIFICATION=abc123...xyz
   ```

4. Re-deploy (Cloudflare will pick this up from the next deploy
   to `main`). For local dev, just restart the dev server.

### 3. Verify in GSC

1. Back in GSC, click **Verify**. Google will check the rendered
   HTML of `https://gileara.org` for the meta tag.
2. Once verified, submit the sitemap:

   ```
   https://gileara.org/sitemap.xml
   ```

3. Optional but recommended: also submit the **individual**
   priority pages via URL Inspection → **Request indexing** for
   the homepage and 1-2 service pages, to speed up discovery.

### 4. What to monitor in the first 4 weeks

- **Coverage → Excluded** — shows pages Google knows about but
  didn't index. Most are 404s (we have a few legacy routes), or
  pages blocked by `noindex` (we don't use it; should be 0).
- **Coverage → Errors** — anything here is a real problem.
- **Enhancements** — Mobile Usability, Core Web Vitals. Should
  be all green if Lighthouse passes.
- **Links → External** — once you start getting backlinks, this
  is where to track them.

## Bing Webmaster Tools

### 1. Add the site

1. Go to https://www.bing.com/webmasters
2. Click **Add a site** → enter `https://gileara.org`
3. Choose **HTML meta tag** verification
4. Bing will give you:

   ```html
   <meta name="msvalidate.01" content="DEF456..." />
   ```

### 2. Paste the code

Edit `.env.production` and `.env.local`:

```
BING_SITE_VERIFICATION=DEF456...
```

### 3. Verify

Click **Verify** in Bing Webmaster. Then submit the sitemap:

```
https://gileara.org/sitemap.xml
```

## Yandex (optional — for Russian-language traffic)

Same flow. Env var: `YANDEX_SITE_VERIFICATION=...`. Skip until
you actually have Russian-language visitors.

---

## What you DON'T need to do

- **robots.txt** — already deployed at `https://gileara.org/robots.txt`.
  No action needed.
- **sitemap.xml** — auto-generated by `src/app/sitemap.ts` on
  every build. No action needed.
- **JSON-LD structured data** — already emitted on every page
  (Organization, Person, BlogPosting, BreadcrumbList, FAQPage,
  WebPage, Service, JobPosting, HowTo). GSC's **Enhancements**
  tab will validate these once indexed.

---

## After setup

- GSC data lag is 2-3 days for new properties, then 1-2 days
  for updates. Don't panic if it looks empty at first.
- Bing is faster to crawl than Google but has lower market
  share. Use it as a secondary signal.
- Neither tool gives you rankings — they only tell you how the
  crawler sees your site. Track rankings with a separate tool
  (Google Search Console's **Performance** tab is enough to
  start; paid options like Ahrefs / Semrush only if SEO
  becomes a real channel).
